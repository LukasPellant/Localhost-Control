# Localhost Control v0.1.5

This release refreshes the browser extension packages and native host assets for Chrome Web Store and Mozilla Add-ons publication, while moving the side panel toward the v2 local command-center experience.

New:

- Saved project profiles group local dev servers by project, expected port, localhost URLs, health URL, notes, and launch command.
- Workspace cards summarize multiple saved profiles so a project can be opened, checked, or started from one place.
- Safe process actions default to terminate-tree stops, with explicit force-tree controls for stubborn local dev servers.
- Possible stale or ghost process signals now include review and copyable cleanup advice.
- Detail actions can clear the selected localhost origin, hard-reload matching localhost tabs, and open desktop, tablet, or phone preview windows.
- Profile start flows can notify when a localhost health check becomes ready or fails.

Fixes:

- The Firefox build uses a Firefox sidebar manifest and opens from the toolbar action.
- The Firefox package no longer includes the Chrome-only `background.service_worker` field.
- Chrome toolbar clicks retry opening the side panel after enabling it for the active tab.
- Toolbar open failures are now contained in the background script instead of leaking unhandled promise rejections.
- Corrupt locally saved extension settings now fall back to defaults instead of breaking the panel startup.
- Malformed saved extension settings are sanitized field-by-field before the UI uses them.
- Extension storage read failures now fall back to defaults instead of breaking panel startup.
- Extension storage write failures now show an in-panel error and roll back the pending settings change.
- Browser tab creation failures now show an in-panel error instead of being dropped by the UI.
- Terminal launch failures now show an in-panel error instead of becoming an unhandled action.
- Malformed native host error envelopes now show a clear invalid-response error instead of an empty message.
- Malformed native host responses are rejected at the extension boundary instead of being rendered by the UI.
- Oversized native messaging request frames are rejected before the Rust host attempts to read the payload body.
- Kill responses with invalid PID or port values are rejected at the extension boundary.
- Native host scan validation now rejects unknown port kinds, confidence levels, and invalid PID/port values.
- Linux browser processes such as Google Chrome, Chromium, and Microsoft Edge are protected from kill actions.
- Optional scan fields such as URL, project path, title, and parent PID are now type-checked before the UI renders them.
- Debian native host package validation now verifies the Chrome, Brave, and Firefox native messaging manifest contents.
- Debian native host package validation now honors custom Chrome and Firefox extension IDs.
- macOS pkg validation now expands the payload and verifies Chrome, Brave, and Firefox native messaging manifest contents.
- The detail panel no longer shows a Windows-only `taskkill` command on Linux and macOS.
- Kill results now report `killed: false` when the target port remains open after the native host attempts to stop it.
- macOS listener detection handles `lsof` wildcard and `localhost` addresses.
- IPv6 localhost HTTP probes use the matching `::1` loopback address.
- The native host download prompt resolves the GitHub release tag from the installed extension version.
- Browser cleanup and hard reload actions are scoped to localhost origins.
- Store package validation now verifies the `browsingData`, `notifications`, and optional localhost permissions used for health checks and hard reload tab matching in Chrome and Firefox builds.

Install the browser extension from the Chrome Web Store, or install the Firefox build from Mozilla Add-ons after it is approved:

https://chromewebstore.google.com/detail/localhost-control/oamllgeaemchejbebgamdakjloahgjdc

Then install the native host for your operating system:

- Windows: download `localhost-control-native-host-windows-0.1.5.zip`, extract it, and run `install.ps1`.
- macOS installer: download `localhost-control-native-host-0.1.5.pkg`.
- macOS portable install: download `localhost-control-native-host-macos-0.1.5.tar.gz`.
- Linux Debian/Ubuntu: download `localhost-control-native-host_0.1.5_amd64.deb`.
- Linux portable install: download `localhost-control-native-host-linux-0.1.5.tar.gz`.

The native host packages are built for the published Chrome extension ID `oamllgeaemchejbebgamdakjloahgjdc` and Firefox add-on ID `localhost-control@lukaspellant.dev`.
Use `SHA256SUMS` to verify downloaded files.
