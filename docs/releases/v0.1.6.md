# Localhost Control v0.1.6

This release publishes the v2 command-center work as fresh browser extension and native host packages.

New:

- Saved project profiles can group local dev servers by project, port, URLs, health checks, notes, and launch commands.
- Workspace cards summarize multiple profiles so a local project can be opened, checked, or started from one place.
- Safer process controls default to terminate-tree stops and keep explicit force-tree actions behind stronger confirmation.
- Stale or ghost process signals include copyable diagnostics and cleanup guidance.
- Detail actions can clear selected localhost origin data, hard-reload matching localhost tabs, and open desktop, tablet, or phone preview windows.
- Profile start flows can notify when a localhost health check becomes ready or fails.
- Release publishing includes validated Chrome and Firefox extension ZIPs alongside native host packages for Windows, macOS, and Linux.

Fixes:

- Firefox uses a Firefox sidebar manifest and no longer ships Chrome-only service worker metadata.
- Chrome toolbar clicks retry side-panel opening after enabling the panel for the active tab.
- Corrupt or malformed extension settings fall back to safe defaults instead of breaking panel startup.
- Storage write and browser tab creation failures now surface as in-panel errors.
- Malformed native-host responses are rejected at the extension boundary before the UI renders them.
- Oversized native messaging frames are rejected before the Rust host reads the payload body.
- Native host scan and kill responses validate PID, port, kind, confidence, and optional metadata fields.
- Linux browser processes are protected from kill actions.
- macOS and Linux native host package validators verify Chrome, Brave, and Firefox manifest contents.
- Windows installer manifest validation covers custom registry roots and browser-specific registrations.
- Store package validation covers browsing data, notifications, and optional localhost permissions.

Install the browser extension from the Chrome Web Store, or install the Firefox build from Mozilla Add-ons after it is approved:

https://chromewebstore.google.com/detail/localhost-control/oamllgeaemchejbebgamdakjloahgjdc

Then install the native host for your operating system:

- Windows: download `localhost-control-native-host-windows-0.1.6.zip`, extract it, and run `install.ps1`.
- macOS installer: download `localhost-control-native-host-0.1.6.pkg`.
- macOS portable install: download `localhost-control-native-host-macos-0.1.6.tar.gz`.
- Linux Debian/Ubuntu: download `localhost-control-native-host_0.1.6_amd64.deb`.
- Linux portable install: download `localhost-control-native-host-linux-0.1.6.tar.gz`.

The native host packages are built for the published Chrome extension ID `oamllgeaemchejbebgamdakjloahgjdc` and Firefox add-on ID `localhost-control@lukaspellant.dev`.
If you sideload the Chrome ZIP manually in Brave or Chrome as an unpacked extension, the browser may generate a different extension ID. In that case rerun the Windows installer with `.\install.ps1 -Browser brave -ExtensionId <your-extension-id>` or `.\install.ps1 -Browser chrome -ExtensionId <your-extension-id>`.

Use `SHA256SUMS` to verify downloaded native host files.
